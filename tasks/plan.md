# نقشه اجرا

محصول واقعی است و برش‌ها باید تا دیتابیس و آزمون برسند. رابط بدون اتصال سرور ساخته نمی‌شود.

## انجام‌شده

- اسکلت Flutter، تم، تقویم، پوسته، ورود، داشبورد، ثبت حضور
- مهاجرت‌ها، RLS، تابع‌های سازمان و حضور و کار و مرخصی
- Edge Function ورود، ساخت کارمند، دعوت، تغییر رمز، وضعیت حساب
- آزمون بحرانی SQL و آزمون تقویم Flutter
- صف تأیید حضور و درخواست اصلاح در رابط
- مرخصی روزانه و ساعتی، تقویم تیم، ثبت غیبت و تصمیم اعتراض
- پروژه، تسک، تأیید، چک‌لیست، زیرتسک، کانبان، فهرست و تقویم
- اسپرینت و مایلستون، انتقال تسک ناتمام، و پیشرفت بر اساس تأیید
- صندوق اعلان، خواندن، صفحه‌بندی، و باز کردن رکورد اگر هنوز دیده شود
- داشبورد نقش‌محور، تحلیل حضور و کار و مرخصی، و خروجی اکسل و PDF
- صفحه افراد داشبورد، وضعیت دوره گزارش، خروجی کامل، مجوز خروجی پروژه، و کش فقط‌خواندنی

## برش‌های باقی‌مانده

1. اتصال پروژه Supabase واقعی و ساخت امضاشده پلتفرم‌ها

هر برش وقتی تمام است که مسیر اصلی‌اش در SQL یا ویجت آزمون داشته باشد و دکمه به تابع واقعی وصل باشد.
